# (주)후미디어 영상 품질 검수 플랫폼 & 제안서 전용 QR·링크 제출 시스템

본 시스템은 대학 원격 정규 교육과정 콘텐츠 개발 사업을 위한 **실제 동영상 품질 검수 플랫폼**이자, 입찰 제안서(서류평가)에 삽입할 **기관 전용 QR코드 및 검수 링크를 발급·관리하는 시스템**입니다.

AWS나 Firebase 등 유료 외부 인프라 없이 **GitHub 리포지토리와 Vercel 단독 배포 환경(Vite SPA + IndexedDB + LocalStorage)**만으로 100% 무결하게 동작하도록 구축되었습니다.

---

## 1. 허구 데이터 및 가짜 담당자 전면 정화 내역

1. **허구의 목데이터 영상 및 빈 차시 목록 완전 제거**:
   - 기존의 가짜 강의 영상(외부 샘플 URL, 더미 ID 등) 및 영상 파일이 연결되지 않은 껍데기 세션/주차 리스트를 전면 삭제하였습니다.
   - 실제 영상 파일(MP4, WebM, MOV, MKV)이 업로드된 항목만 검수 테이블과 플레이어에 나타나도록 변경하였습니다.

2. **허구의 인명/담당자 100% 제거**:
   - 하드코딩되어 있던 인명("성진호 교수", "이영희", "박제작", "김관리" 등)과 가짜 이메일을 전부 삭제하였습니다.
   - 실제 작업자가 관리자 콘솔 상단 또는 검수 모달에서 본인의 실명을 입력하면 즉시 반영되고 브라우저 로컬 저장소에 영구 보존되는 동적 사용자 프로필 체계로 전환하였습니다.

---

## 2. 표준 운영 프로세스 ("어떻게 관리하는가?")

유령 리스트(영상이 없는 빈 차시)가 생기는 문제를 방지하기 위해 **실제 영상 파일 중심의 원스톱 관리 체계**로 재설계되었습니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                      표준 관리 프로세스 (4단계)                        │
└────────────────────────────────────────────────────────────────────────┘

  [1단계: 사업 등록]
    대학/기관명(예: 경희사이버대학교) 및 전용 슬러그(예: khcu) 등록
           │
           ▼
  [2단계: 실제 강의 영상 원스톱 업로드]
    MP4/WebM/MOV 원본 파일 선택 + 차시명(예: 1차시 강의 개요) 즉시 입력
    → 로컬 IndexedDB에 영구 보존되고 검수 목록에 즉시 등록
           │
           ▼
  [3단계: 제안서 제출용 QR·링크 발급]
    사업별 전용 링크(/khcu 또는 /?p=khcu) 및 고해상도 QR코드 PNG 원클릭 다운로드
    → 입찰 제안서(HWP, PPT)에 바로 삽입
           │
           ▼
  [4단계: 외부 심사위원 및 사내 검수 진행]
    QR/링크 스캔 시 타사 정보가 100% 격리된 단일 기관 전용 뷰로 접속
    → 프레임 단위 재생, 타임코드 자동 기록 의견 등록, 승인/반려 판정
```

## 3. 핵심 화면 및 기능

1. **관리자 콘솔 (`/admin` 또는 상단 관리자 모드)**:
   - **`[프로젝트 & 영상 관리]` (`ProjectRegistrationView`)**:
     - 운영 프로세스 시각 가이드 안내.
     - 신규 대학 사업 등록 및 슬러그 관리.
     - 실제 강의 영상 원스톱 업로드 영역 (드래그앤드롭 + 즉시 차시 연결).
     - 사업별 등록 현황 및 제안서 전용 고해상도 QR PNG 다운로드.
   - **`[대시보드]` (`AdminDashboard`)**:
     - 승인/반려/대기 실시간 집계 및 검수 완료율 바.
     - 검수 활동 집계 및 CSV 리포트 원클릭 다운로드.
   - **`[동영상 업로드 모달]` (`UploadModal`)**:
     - 상단 헤더 어디서나 실제 영상 파일과 주차/차시명을 입력하여 바로 등록 가능.

2. **외부 심사위원 전용 뷰 (`/?p=khcu` 등)**:
   - 제안서 QR코드 또는 링크로 접속한 외부 평가자에게는 타사 대학 정보가 일체 차단되고 배정된 단일 기관의 영상만 노출.
   - 관리자 전용 메뉴, 업로드 버튼, 제안샘플 편집 기능이 완전히 숨겨진 정통 상용 검수 시스템 UI 제공.

3. **검수 플레이어 모달 (`ReviewModal`)**:
   - HTML5 비디오 스트리밍 및 로컬 IndexedDB Blob 고화질 즉시 재생.
   - 타임스탬프 자동 캡처 의견 등록.
   - 승인 / 반려 / 대기 실시간 상태 판정.
   - AI 자동 자막 생성 및 SRT/VTT 파일 업로드 지원.

## 4. GitHub + Vercel 무결점 빌드 및 배포

- **TypeScript 검증**: `tsc --noEmit` 통과 (0 errors).
- **Vite 번들 빌드**: `compile_applet` 통과 (성공).
- **SPA 라우팅**: `vercel.json`을 통해 새로고침 및 딥링크(`/admin`, `/?p=khcu`) 무결성 보장.
- **인프라 독립성**: AWS S3/Firebase 연동 키가 없어도 브라우저 내 IndexedDB와 LocalStorage를 통해 영상과 데이터가 100% 정상 작동.
