# WHOMEDIA 제안샘플 사이트 & QR코드·URL 생성 시스템 구축 계획

(주)후미디어 입찰 및 제안서 서류평가 시 평가위원이 스마트폰으로 즉시 시청할 수 있도록 제안서에 삽입하는 **샘플 사이트 URL과 QR 코드를 별도 외주/업무요청 없이 사내에서 직접 생성·관리하는 독립 솔루션**을 구축합니다.

---

> [!IMPORTANT]
> ### 사용자 확인 및 결정 사항 요약
> - **메뉴 및 화면 구성**: 좌측 사이드바에 **`[제안샘플 사이트]` 전용 메뉴**를 신설하고, 평가위원용 클린 쇼케이스와 사내 등록/관리 기능이 결합된 독립 뷰 제공
> - **QR코드 및 URL 제공 방식**: 화면 내 실시간 QR코드 렌더링 + 제안서 삽입용 **고해상도 QR 이미지 다운로드(PNG/SVG)** + **원클릭 URL 복사** 지원
> - **샘플 카드 등록 방식**: 폼 직접 입력(강좌명, 기관명, 강의유형, 특징 불릿)과 기존 검수 영상에서의 **'제안샘플로 원클릭 지정'** 두 가지 방식을 모두 지원

---

## 1. 개요 및 핵심 목적 (Overview & Core Concept)

- **배경**: 공공기관, 대학교(경희사이버대, 인하대 등) 입찰 제안서 제출 시, 서류평가 위원들이 실물 제안서 책자나 PDF에서 직접 샘플 영상을 확인할 수 있도록 URL과 QR코드를 필수로 삽입합니다.
- **해결 과제**: 기존에는 개발/디자인팀에 매번 별도 '업무요청'을 거쳐야 했던 비효율을 제거하고, 사내 직원이 원하는 강의 샘플을 선택/등록하면 **즉시 검증된 쇼케이스 URL과 인쇄용 QR코드**를 자동 발급받을 수 있도록 내재화합니다.
- **주요 산출물**:
  1. 첨부 이미지(경희사이버대학교 샘플 카드)와 100% 일치하는 반응형 제안샘플 쇼케이스 카드 UI
  2. 서류 인쇄 규격에 최적화된 QR 코드 생성기 및 이미지 다운로더
  3. 기관별/강의유형별(1인강의형, 대담형, 크로마키형, 모션그래픽형) 필터링 및 고화질 스트리밍 팝업
  4. 검수 영상 테이블과의 원클릭 '제안샘플 지정' 연동

---

## 2. 사용자 경험 및 시각 디자인 (UX & Visual Design)

### A. 제안샘플 카드 UI (첨부 이미지 1:1 구현)
- **카드 상단**: 16:9 비율의 고화질 영상 썸네일 (성진호 교수 '시니어 재무컨설팅', '세무실무적용사례' 등 실제 참조 에셋 및 썸네일 탑재, 마우스 호버 시 세련된 재생 버튼 오버레이)
- **카드 본문**:
  - **강좌명**: 블루 다이아몬드 불릿(`◆`) + 볼드 강좌 타이틀 (Pretendard Bold, 16px)
  - **기관명**: 의뢰 대학교/기관 표기 (예: `경희사이버대학교`, `인하대학교` 등)
  - **강의 형태 뱃지**: `1인강의형`, `크로마키형`, `스튜디오형`, `대담형`, `모션그래픽형` 등 은은한 파스텔 블루 뱃지 (`bg-sky-100 text-sky-800 font-semibold px-2.5 py-0.5 rounded-md`)
  - **특징 요약 불릿**: `• 사진, 영상 등의 다양한 시각적 자료를 효과적으로 활용`, `• 교수자 시선 처리 및 최신 스튜디오 조명 연출` 등 제안서 맞춤형 특장점 리스트

### B. 서류평가용 QR코드 & URL 툴바 (Proposal Exporter Bar)
- 상단 배너에 **제안서 삽입용 QR코드 팝업/다운로더** 제공:
  - 평가위원이 접속할 공개 쇼케이스 URL 표시 (예: `https://.../sample` 또는 기관별 맞춤 링크)
  - 제안서 인쇄용 고해상도 QR코드 프리뷰
  - **[QR코드 이미지 다운로드 (PNG)]**: 제안서 한글/워드/PPT 문서에 바로 드래그앤드롭 할 수 있는 투명 배경 고화질 이미지
  - **[제안서용 URL 복사]**: 클립보드에 원클릭 복사 및 피드백 토스트

### C. 평가위원용 클린 재생 모달
- 카드 클릭 시 군더더기 없는 풀 HD 비디오 플레이어 오픈 (재생, 타임라인, 볼륨 제어)
- 평가위원이 심사에만 집중할 수 있도록 검수자용 의견 작성란은 숨기고 콘텐츠 완성도에 집중

## 3. 기능 및 데이터 흐름 (Architecture & Workflow)

```
┌─────────────────────────────────────────────────────────────┐
│                    사내 사이드바 메뉴                       │
│  [동영상 강의 검수]  [프로젝트 관리]  [⭐ 제안샘플 사이트]    │
└──────────────────────────────┬──────────────────────────────┘
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
┌───────────────────────────┐         ┌───────────────────────────┐
│     제안샘플 관리 & 발급   │         │    평가위원 쇼케이스 뷰   │
│ - 신규 샘플 카드 직접 등록│         │ - 첨부 이미지와 동일한    │
│ - 검수 영상에서 원클릭 추가│         │   ◆ 강좌명 카드 그리드    │
│ - QR코드 실시간 렌더링   │         │ - 강의유형 필터(1인강의등)│
│ - [QR 다운로드] [URL 복사]│         │ - 고화질 비디오 재생 팝업 │
└───────────────────────────┘         └───────────────────────────┘
```

### 샘플 데이터 모델 (`ProposalSampleItem`)
- `id`: 고유 식별자
- `title`: 강좌명 (예: `시니어재무컨설팅`, `세무실무적용사례`)
- `institution`: 기관명 (예: `경희사이버대학교`)
- `lectureType`: 강의 형태 (`1인강의형` | `크로마키형` | `대담형` | `모션그래픽형` 등)
- `descriptionBullets`: 특장점 불릿 배열 (`['사진, 영상 등의 다양한 시각적 자료...', ...]`)
- `thumbnailUrl`: 썸네일 이미지 경로 (첨부 에셋 활용)
- `videoUrl`: 시연용 비디오 스트림 URL
- `instructor`: 교수자명 (예: `성진호 교수`)
- `createdAt`: 등록 일시

## 4. 검증 계획 (Verification Plan)

1. **카드 레이아웃 정밀 검증**: 첨부된 2장의 스크린샷과 폰트 크기, 여백, 다이아몬드 불릿(`◆`), 뱃지 컬러가 일치하는지 확인.
2. **QR코드 및 URL 생성 검증**:
   - 모바일 기기 카메라로 스캔 가능한 표준 QR코드 SVG/Canvas가 브라우저에 정상 생성되는지 테스트.
   - [QR 다운로드] 버튼 클릭 시 PNG 이미지 파일 저장이 정상 작동하는지 확인.
   - [URL 복사] 버튼 클릭 시 복사 완료 토스트 및 링크 유효성 검증.
3. **등록 기능 검증**:
   - 직접 폼 입력으로 새 강좌 등록 후 즉시 카드 그리드에 반영되는지 확인.
   - 영상 검수 테이블에서 '제안샘플 추가' 버튼으로 연동되는지 확인.
4. **빌드 무결점 검증**:
   - `lint_applet` (`tsc --noEmit`) 0건 통과 확인.
   - `compile_applet` (`vite build`) 정상 완료 확인.
